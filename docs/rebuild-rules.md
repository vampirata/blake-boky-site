# Rebuild rules (from Kait, 28 Oct 2026)

1. Visuals are 1:1 with the live Framer site: layout, type, colour, spacing, motion, at every breakpoint (Desktop >= 1400, Tablet 810 to 1399, Phone < 810).
2. Bugs and errors are fixed, not reproduced. Every fix is listed in `docs/fixes.md` so the client can see what changed.
3. Images are never cut off in a way that hides the artwork (Valentina's note). Galleries, cards and thumbnails show the whole piece.
4. Content and assets are the client's exact ones. Client copy is kept verbatim except obvious bugs (template leftovers, unfilled placeholders, wrong labels), which are fixed and listed.
5. No em or en dashes in any copy we write.
